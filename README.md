# Travel Unbounded

A responsive full-stack travel website built with **Next.js, React, Tailwind CSS, Mongoose, and MongoDB Atlas**.

## Features

- Responsive travel website
- India & international destinations
- Reusable React components
- Travel enquiry form
- Client & server-side validation
- Loading, success & error states
- MongoDB enquiry persistence
- SEO metadata
- Vercel-ready

## Tech Stack

- Next.js
- React
- JavaScript / JSX
- Tailwind CSS
- MongoDB Atlas
- Mongoose
- Vercel

## Project Structure

```text
app/          Pages, layout & API
components/   Reusable React components
data/         Destination data
